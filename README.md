# odin-recipes
A repo of my 1st TOP project: a recipe website. 

This website shows a homepage with multiple links to recipes. 
The recipes show a picture of the dish / item, an ingredients list, 
and a step-by-step recipe to follow. Each recipe page also has a link
back to the original homepage.

This project helped me practice a lot of things in HTML, including
HTML entities, HTML syntax and formatting, linking to other websites,
linking pictures, setting up and formatting pictures, and (maybe 
most importantly) using git commands!
